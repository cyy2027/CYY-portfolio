## 一、项目简介
本固件为12自由度四足机器人**对角小跑(Trot步态)**主控程序，采用**一主多从分布式CAN总线架构**：主控MCU负责整机姿态解算、步态相位调度、故障安全管理；4个关节伺服独立下沉FOC闭环控制，实现算力分层解耦。

核心目标：实现稳定Trot连续行走；通过五次多项式轨迹抑制落地冲击；自适应互补滤波抑制机身振动带来的姿态漂移；搭建四级分级故障保护机制，兼顾硬实时性与设备安全性。

## 二、整体架构与技术栈
### 软硬件架构
- 主控：STM32F4（Cortex-M4，硬件FPU）
- 实时系统：FreeRTOS，基于SysTick统一时间戳，全任务非阻塞调度
- 总线：CAN2.0B，分布式多节点通信，带帧校验与丢包重传容错
- 感知：ICM20602六轴IMU，自适应互补滤波姿态融合
- 运动算法：正/逆运动学、五次多项式足端轨迹、Trot步态相位调度、机身姿态补偿
- 安全机制：四级故障分级、Flash参数持久化、平滑停机保护

### 技术栈
STM32F4 | FreeRTOS | CAN2.0B | ICM20602 | 自适应互补滤波 | 五次多项式轨迹 | 逆运动学 | 非阻塞状态机

## 五、核心关键特性
1. **严格时序节拍，硬实时控制**
   1kHz关节目标角度CAN下发帧；200Hz步态调度主循环；全局统一SysTick时间戳，实现四条对角腿相位严格对齐；全程无`delay()`阻塞，全部采用事件+Tick驱动状态机。

2. **五次多项式零冲击足端轨迹**
   摆动相采用五次多项式插值，约束起点/终点位置、速度、加速度全部为0，相比梯形轨迹大幅降低落地冲击，减小减速器机械磨损；支撑相匀速运动，保证机身平稳。

3. **抗振动IMU姿态融合算法**
   传统固定权重互补滤波在落地冲击阶段会被振动噪声污染，导致姿态漂移；本方案增加冲击检测标志，动态降低加速度计权重、提升陀螺仪权重，实现行走过程中姿态稳定收敛。

4. **分级故障保护，杜绝粗暴停机**
   划分四级故障等级；出现致命故障时，先执行平滑收腿动作，逐步降低关节力矩，再停机，避免瞬间抱死造成齿轮、编码器损坏；故障信息实时通过CAN上传，同时存入Flash日志。

5. **参数持久化存储**
   IMU零偏、关节零位、连杆尺寸、步态调参参数全部存入片内Flash；每次上电自动加载，并附带CRC校验，防止参数损坏；支持在线改写参数，无需重新编译固件。

6. **中断轻量化设计，避免时序抖动**
   仅在中断内完成CAN数据接收与缓存；CAN报文发送、IMU数据解算全部放到任务中执行；合理配置NVIC中断优先级，防止IMU高优先级中断抢占CAN发送任务，消除控制帧时序抖动。

## 六、硬件清单
- 主控MCU：STM32F407（Cortex-M4，带硬件FPU）
- 惯性传感器：ICM20602（I2C通信）
- 执行单元：4路关节伺服（内置FOC矢量闭环控制器）
- 总线电路：CAN2.0B收发器+总线终端电阻
- 结构：减震安装支架，降低机身振动对IMU的干扰

## 七、完整调试复盘（/debug_log）
1. **问题1：步态控制帧时序抖动**
   现象：IMU外部中断频繁抢占CAN发送任务，导致下发周期波动，步态出现卡顿。
   解决方案：把CAN发送操作移出中断，全部放到低优先级任务；重新划分中断优先级，保证通信任务时序稳定。

2. **问题2：足端落地冲击大，机身剧烈抖动**
   现象：梯形轨迹起止点加速度突变，落地瞬间冲击力大。
   解决方案：替换为五次多项式轨迹，约束边界条件，保证启停时刻速度、加速度均为零，实现零冲击落地。

3. **问题3：行走时机身姿态持续发散漂移**
   现象：落地冲击带来高频振动，固定权重互补滤波会被噪声污染，重力观测失真。
   解决方案：增加冲击检测位，自适应动态调整滤波权重，冲击阶段弱化加速度计数据，依靠陀螺仪维持姿态稳定。

4. **问题4：故障保护逻辑粗暴，容易打坏机械结构**
   现象：触发故障时直接关闭PWM，关节瞬间抱死，多次打坏减速器。
   解决方案：设计分级保护策略，致命故障先执行平滑收腿轨迹，缓慢减小力矩，再停机，实现柔性保护。

## 八、配套工具（tools目录）
- `gait_plot.py`：离线求解五次多项式轨迹，绘制位置/速度/加速度曲线，提前验证轨迹平滑度，避免反复烧录固件调试。
- `can_log_parse.py`：解析CAN总线日志，统计帧传输时延、丢包率，排查总线通信稳定性。
- `imu_data_analysis.py`：读取IMU原始数据，对比滤波前后姿态曲线，调试互补滤波参数。
- `joint_calibrate.py`：下发角度指令，单关节点动调试，完成机械零位标定。

> 约定：所有Python脚本仅用于离线调试与算法验证，不参与整机实时控制；脚本生成的波形、测试数据统一归档至`docs/debug_log/`，形成完整可追溯的调试链路。

## 九、性能指标（design.md）
- 步态调度周期：200 Hz
- 关节指令下发周期：1000 Hz
- CAN单帧传输时延：＜3 ms
- 多关节同步误差：＜1 ms
- 姿态融合延迟：＜5 ms
- 连续运行稳定性：无任务栈溢出、无总线丢包、无姿态发散
