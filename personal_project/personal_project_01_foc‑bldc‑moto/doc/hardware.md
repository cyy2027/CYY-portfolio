# FOC-BLDC 无刷电机控制器｜硬件说明文档
## 硬件清单
| 器件 | 型号 | 说明 |
|---|---|---|
| 主控MCU | 正点原子 STM32F103xE | Cortex-M3，72MHz，HAL库开发 |
| 功率驱动板 | SimpleFOC Mini | 三相PMSM驱动 |
| 永磁同步电机 | 2804外转子PMSM | 无刷云台电机 |
| 位置传感器 | AS5600磁编码器 | I2C接口，12bit角度采集 |
| 无线协处理器 | 嘉立创 ESP32 + ESP8266模组 | 串口与STM32通信，WiFi数据转发、远程调参 |

## 硬件信号链路
1. 角度采集链路：AS5600(I2C) → STM32，读取转子机械角度
2. 功率控制链路：STM32 TIM1生成40kHz三相中心对齐PWM → SimpleFOC Mini驱动板 → 2804 PMSM电机
3. 无线通信链路：STM32串口 ↔ ESP32/ESP8266协处理器 ↔ 上位机/网页端，实现电机参数远程下发、运行状态上传
4. 预留接口：USART3语音桥接接口，可外接语音模块

## 定时器资源分配
- TIM1：高级定时器，输出40kHz中心对齐三相PWM，电机驱动波形
- TIM3：通用定时器，500Hz定时中断，FOC闭环运算周期

## 通信资源分配
- USART1：本地PC串口调试，打印日志、接收本地控制指令
- USART2：与ESP32+ESP8266无线模组通信
- USART3：预留语音桥接扩展接口

## 硬件设计要点
1. 功率地与信号地单点共地，降低电机功率侧噪声干扰编码器采样
2. AS5600磁编码器增加0.1uF去耦电容，减少电源噪声引入角度抖动
3. 无线模组独立供电，避免WiFi射频干扰主控模拟采样
4. 光耦隔离预留位，可增加强电隔离保护（当前版本未焊接）

## ⚠️硬件局限
1. 无板载电流采样电路，当前为电压模式FOC，缺少电流内环与过流硬件保护
2. 无温度传感器，无法监测驱动板与电机温度
