# TEC恒温控制器 — 上位机使用手册
> 支持两套上位机：安卓BLE APP、VOFA+电脑上位机。
下位机串口参数：**波特率115200，8‑N‑1**
通信指令集：
|指令|说明|
|---|---|
|`SETXXTMP`|设置目标温度，例：`SET24TMP` 设置24℃|
|`STOP`|停止TEC温控输出|
> 整机硬件参数、硬件操作请看：[用户使用说明](./user_guide.md)

## 1 安卓BLE APP使用
1. 手机开启蓝牙、开启定位（BLE蓝牙权限强制需要定位）
2. 上电开启恒温控制器
3. APP扫描并连接设备
4. 输入目标温度，点击设置下发；点击STOP停止温控
5. 设备达到恒温条件，APP提示【温度已稳定】，并绘制实时温度曲线

> 现象：红色设定温度；绿色腔体温度；黄色环境温度；蓝色散热片温度

## 2 VOFA+电脑上位机使用
### 2.1 硬件准备
1. 需要2块蓝牙模块：一块接恒温设备主板；另一块接【蓝牙串口PCB小板】，插电脑USB。
> 蓝牙串口PCB适配旧ST‑LINK外壳；铁质外壳务必做绝缘，防止短路。

### 2.2 VOFA+软件配置
1. 打开VOFA+，数据引擎选择 `JustFloat`
2. 选择蓝牙虚拟COM串口，波特率设置 `115200`
3. 控件库把波形控件拖入主窗口
4. ΔT采样间隔设置 **500ms**，必须和下位机上报间隔保持一致
5. Y轴选择 `All`，X轴选择【使用时间轴】

### 2.3 蓝牙连接AT指令
> 将MAC地址替换成你自己蓝牙模块MAC；发送选项设置为【无追加】，不加换行/回车。
```

AT+CONN=F938911A941D,1\r\n

```
发送成功后，电脑蓝牙与硬件建立通信，即可接收温度数据流。

> VOFA+会自动保存上次配置，下次打开直接点左上角蓝色圆圈连接。

## 3 本地硬件操作（备用，不上位机）
1. 旋转EC11编码器修改目标温度
2. 按下编码器确认启动温控；备用按键B按下执行STOP停止。

## 4 常见问题排查
1. VOFA收不到数据：确认波特率115200；确认AT指令MAC地址正确；确认发送选项【无追加】。
2. 安卓APP搜不到设备：确认手机定位、蓝牙权限；设备正常上电。
3. 温控无反应：确认供电DC9‑15V，风扇正常转动。
