# TEC双向恒温控制器 用户使用说明
## 硬件参数
- 控温区间：0 ~ 52 ℃
- 腔体尺寸：20 × 20 × 6 mm
- 控制精度：优于 ±0.25 ℃；腔体内温度梯度＜0.5 ℃
- 供电：DC 9‑15V，推荐12V‑3A适配器，DC5.5×2.5接口
> ⚠️ **严禁接入24V，会烧毁设备**
- 恒温判定条件：温度误差＜0.25℃ **且** 温度变化率＜0.08 ℃/s
- 典型稳定时间：普通工况约3分钟；靠近散热片±3℃工况最长约10分钟

## 硬件安全重要提醒
1. TEC热面散热风扇**必须正常工作**；风扇停转会直接烧毁TEC半导体制冷片。
2. 不要超过52℃长时间加热，硬件做温度上限保护。
3. 供电只能使用9‑15V直流电源。

## 本地硬件操作
1. 旋转EC11编码器调整目标温度；按下编码器确认启动温控。
2. 备用按键B：按下执行STOP，停止TEC输出。
3. LED状态指示
    - 蓝灯：制冷模式
    - 红灯：加热模式
    - 绿灯：已经达到恒温稳定

## 两种控制方式
1. **本地硬件**：编码器+按键，直接板上操作。
2. **蓝牙上位机控制**：安卓APP / VOFA+电脑上位机。
> 上位机详细操作：[上位机使用手册](./upper_manual.md)
