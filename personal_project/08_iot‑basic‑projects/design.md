# 嵌入式基础与物联网综合实践详细设计文档
## 1 需求概述
### 1.1 功能需求
1. offline_voice_speaker离线语音蓝牙音箱
    - A2DP蓝牙音频播放；离线KWS语音唤醒识别。
    - AD按键、红外遥控器、语音指令三路输入，控制WS2812彩灯。
2. smart_greenhouse智能温室大棚
    - 采集环境温湿度传感器数据，OLED本地显示。
    - MQTT对接阿里云IoT平台，数据上报云端，接收APP远程控制指令。
    - 环境阈值自动调控；EEPROM存储阈值参数，断电保存；Wi‑Fi断线自动重连。
3. ecg_monitor心电采集监测仪
    - AD8232采集人体微弱心电模拟信号。
    - DMA+ADC高速采样，定时器控制采样节拍。
    - UART接收上位机指令，配置采样率、采集时长；串口输出采样数据给Python上位机绘制波形。
    - 采用驱动‑业务‑调试三层软件架构，调试模块支持条件编译裁剪。

### 1.2 非功能需求
1. 语音音箱多路输入不能发生事件冲突；
2. 温室设备网络不稳定情况下尽量自动恢复，适合无人值守；
3. 心电微弱信号抑制噪声，保证波形可用性；
4. ADC采样尽量降低CPU占用。

## 2 硬件平台
1. 离线语音音箱：杰理Byle‑U8音频SoC；WS2812 RGB灯珠；AD按键；红外接收管；蓝牙天线。
2. 智能温室大棚：ESP32；温湿度传感器；OLED；继电器执行模块；EEPROM。
3. 心电采集监测仪：STM32F103；AD8232心电模拟放大模块；电源滤波电路；串口USB转TTL。

## 3 软件总体设计
### 3.1 offline_voice_speaker 离线语音蓝牙音箱
1. A2DP蓝牙音频配置，完成音频流播放。
2. KWS离线语音识别：注册唤醒词、控制指令，识别产生事件回调。
3. AD按键扫描、红外解码，产生对应事件。
4. **事件消息队列**：语音、按键、红外产生的事件送入队列，主循环取出事件，统一执行彩灯控制逻辑，避免多路输入并发冲突。
5. WS2812驱动，根据不同事件切换灯光模式。

> 坑点：多路输入同时触发，如果直接在回调里面执行业务，会出现重复动作、逻辑错乱，必须用事件队列解耦。

### 3.2 smart_greenhouse 智能温室大棚
1. 传感器周期读取环境温湿度，OLED刷新显示。
2. EEPROM读写：存储温度、湿度阈值，上电加载参数。
3. MQTT客户端对接阿里云IoT：设备三元组完成认证；实现指数退避断线重连逻辑。
4. 业务逻辑：
    - 本地：判断环境是否超出阈值，自动控制继电器开关外设。
    - 云端：上报传感器数据；接收APP下发指令修改阈值、手动控制外设。

### 3.3 ecg_monitor 心电采集监测仪
三层软件架构：
1. **驱动层**：ADC、DMA、TIM、UART外设底层驱动；AD8232无软件配置，依靠硬件放大输出模拟电压。
2. **业务层**：定时器触发ADC DMA采样；UART空闲中断解析上位机指令；滑动平均滤波处理心电采样数据；组帧上报采样数据。
3. **调试层**：调试打印、参数打印；使用条件编译，可以整体关闭调试模块，减少代码量。

采样流程：
1. TIM定时器定时触发ADC转换；DMA自动搬运ADC结果到内存缓冲区。
2. 业务层读取缓冲区采样值，软件滤波。
3. 收到上位机指令，可以修改采样参数；将心电原始数据串口输出给Python上位机绘图。

## 4 踩坑记录（面试高频）
1. **离线音箱多路输入并发，业务逻辑重复执行**
现象：同时按下按键+语音识别触发，彩灯多次切换模式。
解决：回调函数只生产事件，送入消息队列；主循环统一消费事件，回调中不执行业务逻辑。

2. **ESP32 Wi‑Fi短暂断网，MQTT不再自动恢复连接**
现象：网络抖动之后设备不再上报数据。
解决：实现指数退避重连逻辑，检测连接状态，断开后间隔递增重试连接阿里云。

3. **心电信号噪声大，波形几乎无法分辨**
现象：工频干扰，波形抖动严重。
解决：AD8232增加硬件滤波电容；软件增加滑动平均滤波；供电尽量使用隔离电源减少工频干扰。

4. 直接CPU读取ADC，采样占用大量CPU资源
解决：配置DMA搬运ADC结果，CPU只需要处理缓冲区数据，不需要干预每一次ADC转换。

5. EEPROM频繁写，缩短芯片寿命
解决：参数只有修改的时候才写入EEPROM，不要周期循环写入。

## 5 测试结果
1. 离线语音音箱：蓝牙音乐播放正常；离线语音识别可用；语音、按键、红外均可控制彩灯，多路输入不会冲突。
2. 智能温室大棚：本地阈值自动调控生效；阿里云MQTT双向通信；断网后自动重连；参数断电保存。
3. 心电采集仪：DMA高速采样正常；上位机可以绘制出清晰心电波形；软件分层架构支持裁剪调试模块。

## 6 扩展优化方向
1. 语音音箱增加音频录音功能；
2. 温室增加本地日志保存到SD卡；
3. 心电增加R‑R间期计算、简单心率算法。
