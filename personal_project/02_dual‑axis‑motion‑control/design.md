# 双轴运动控制平台详细设计文档
## 1 需求概述
### 1.1 功能需求
1. 直流轴：PWM驱动H桥，霍尔编码器测速，增量式PID闭环调速；支持正反转，过流故障检测。
2. 步进轴：脉冲‑方向驱动模式；实现梯形、S型加减速，实现位置定位。
3. 通信：CAN、Modbus‑RTU接收上位机指令：设置转速、设置目标位置、启停、双轴联动。
4. 状态上报：转速、位置、故障状态上报上位机。

### 1.2 非功能需求
1. 运动控制任务高实时性；
2. 步进高速运行尽量不丢步；
3. 直流电机带负载扰动可以快速恢复转速；
4. 长时间运行整机稳定。

## 2 硬件设计
1. 主控：STM32F103
2. 直流电机驱动：IR2104S + MOS管H桥；TIM输出PWM；硬件过流采样。
3. 霍尔正交编码器：TIM硬件正交解码接口，自动计数。
4. 步进驱动：脉冲+方向引脚输出，外接步进驱动模块。
5. 通信外设：CAN外设；USART外接RS485收发芯片。

> 注意：H桥配置PWM死区时间，防止上下MOS管直通烧毁。

## 3 软件总体设计
基于FreeRTOS多任务架构
|任务|优先级|功能说明|
|----|------|--------|
|motion_ctrl_task|高|PID运算、加减速计算、PWM/脉冲输出更新；运动闭环逻辑|
|cmd_parse_task|中|CAN、Modbus‑RTU报文解析，解析上位机指令|
|report_task|低|周期上报转速、位置、故障状态|

共享资源：电机参数结构体，多任务访问加互斥锁保护。

### 3.1 直流轴软件设计
1. TIM硬件正交解码，得到编码器计数值；做前后计数值差值，计算实际转速。
2. 增量式PID计算输出PWM占空比；增加积分限幅，防止积分饱和。
3. PWM输出更新H桥；根据符号控制电机正反转。
4. 过流采样，超过阈值标记故障，关闭PWM输出。

> PID公式：
$$\Delta u(k)=K_p\left[\Delta e(k)+K_i \cdot e(k)+K_d(\Delta e(k)-\Delta e(k-1))\right]$$

### 3.2 步进轴软件设计
- 工作模式：脉冲‑方向模式；方向引脚决定正反转；脉冲产生步进角。
- 梯形加减速：加速段、匀速段、减速段三段速度曲线。
- S型加减速：对加速度做平滑，进一步减小冲击，适合高速场景。
- 根据目标位置，计算总脉冲数；按照速度曲线输出脉冲。

> 坑点：不能直接固定频率输出脉冲，否则启停冲击大，高速丢步。

### 3.3 Modbus‑RTU / CAN通信模块
1. Modbus‑RTU：RS485，UART空闲中断+环形缓冲区接收；CRC校验；实现读写寄存器，设置转速、位置，读取状态。
2. CAN通信：标准数据帧；自定义指令ID；下发控制指令，上报运动状态。

报文示例 Modbus：
- 设置直流电机转速：写保持寄存器
- 设置步进电机目标位置：写保持寄存器
- 读取电机实时转速、位置：读保持寄存器

## 4 关键问题与踩坑记录（面试高频）
1. **正交编码器溢出，转速计算异常**
现象：编码器计数值到达最大值溢出归零，直接读取计数值做运算，转速计算错乱。
解决：计算前后两次计数值的差值，处理溢出边界，而不是直接使用绝对计数值。

2. **直流电机大负载，积分饱和，启停超调严重**
现象：目标转速阶跃输入，PID积分大量累积，转速超调很大。
解决：使用增量式PID，增加**积分限幅**，输出限幅。

3. **步进电机直接阶跃输出脉冲，高速丢步**
现象：直接给最高频率脉冲，电机来不及响应，出现丢步，定位不准。
解决：实现梯形/S型加减速，平滑速度曲线。

4. **多任务访问电机参数结构体，数据竞争**
现象：指令任务修改目标转速，运动控制任务同时读取，参数错乱，电机抖动。
解决：电机参数结构体访问增加互斥锁。

5. **H桥缺少死区时间，MOS管直通**
现象：PWM上下管同时导通，MOS发热严重。
解决：TIM配置PWM死区时间，硬件层面保护。

6. Modbus‑RTU串口粘包，解析错误
解决：UART空闲中断 + 环形缓冲区，完整接收一帧再解析。

## 5 测试结果
1. 直流轴0‑3000rpm调速，空载误差＜1%；突加负载200ms恢复稳态。
2. 步进轴1000rpm运行无丢步，定位精度 ±0.1°。
3. CAN、Modbus‑RTU指令控制正常，双轴联动延迟≤10ms，长时间运行稳定。

## 6 扩展优化方向
1. 增加限位开关，硬件限位保护；
2. 增加回零寻原点逻辑；
3. 支持轨迹插补算法。
