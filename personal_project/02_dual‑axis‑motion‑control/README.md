# STM32双轴运动控制平台（直流+步进）
## 项目简介
本项目基于STM32F103搭建双轴运动原型平台：一路直流电机做速度闭环，一路步进电机做位置定位。
直流电机使用H桥驱动+霍尔正交编码器，实现调速闭环；步进电机支持梯形、S型加减速抑制启停丢步。
基于FreeRTOS做多任务拆分，对外提供CAN、Modbus‑RTU两种通信接口，接收上位机指令实现单轴控制与双轴联动，适合运动控制、自动化设备学习验证。

## 系统架构
1. **直流轴**：IR2104S+H桥MOS驱动，TIM输出PWM；TIM正交解码读取霍尔编码器；增量式PID做速度闭环。
2. **步进轴**：脉冲‑方向模式驱动，软件实现梯形/S型加减速算法，抑制高速启停丢步。
3. **软件层 FreeRTOS**
    - 运动控制任务：PID运算、加减速算法、PWM输出更新
    - 指令解析任务：解析CAN / Modbus‑RTU上位机指令
    - 状态上报任务：转速、位置、故障状态上报上位机
4. **上位机链路**：CAN总线、RS485 Modbus‑RTU，支持单轴调速、正反转、定位、双轴联动。

## 技术栈
STM32F103、FreeRTOS、IR2104S H桥驱动、霍尔正交编码器、增量式PID、梯形/S型加减速、CAN、Modbus‑RTU

## 核心功能
1. 直流电机：0‑3000rpm宽域调速，增量PID闭环调速；支持正反转，带载扰动快速恢复稳态。
2. 步进电机：梯形、S型加减速算法；高速运行抑制丢步，实现精准位置定位。
3. 故障保护：硬件过流检测、PWM死区时间控制；异常状态上报上位机。
4. 通信：CAN / Modbus‑RTU接收上位机指令，支持双轴独立控制、双轴联动。

## 关键难点与解决方案
1. **直流电机带载扰动转速波动**
单纯P开环带负载转速跌落严重；采用增量式PID闭环，调试积分限幅抑制积分饱和，突加负载快速恢复转速。

2. **步进电机高速启停丢步**
直接阶跃输出脉冲，启停冲击大出现丢步；软件实现梯形、S型加减速曲线，平滑速度变化，消除冲击。

3. **多任务下运动控制实时性保障**
运动控制属于高实时任务，设置高任务优先级；通信解析、状态上报放在较低优先级任务；共享变量互斥锁保护，防止数据竞争。

4. **正交编码器计数溢出**
编码器计数值会溢出，做差值计算转速，而不是直接读取绝对计数值，处理正负转向。

## 实测指标
- 直流轴：0‑3000rpm宽域调速，空载稳速误差＜1%；突加负载200ms恢复稳态
- 步进轴：1000rpm运行无丢步，定位精度 ±0.1°
- 双轴联动响应延迟 ≤10ms，长时间整机稳定运行
