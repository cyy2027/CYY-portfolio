# 四轴无人机飞控系统
## 项目简介
基于STM32F4搭建小型四轴无人机飞控原型，移植FreeRTOS做任务化架构；使用MPU6050六轴陀螺仪加速度计获取姿态原始数据，通过互补滤波做姿态解算，采用**串级PID（角度环+角速度环）**输出四路PWM驱动无刷电机，实现飞行器稳定悬停。针对高速飞行机体剧烈震荡问题，从任务优先级、PID参数、传感器滤波多维度完成故障定位与优化。

## 系统架构
1. **硬件层**
- STM32F4主控；MPU6050(I2C)六轴传感器；四路TIM定时器PWM输出驱动无刷电调；无线接收机获取遥控摇杆指令。
2. **软件FreeRTOS多任务拆分**
- 姿态解算任务：读取MPU6050原始传感器数据，互补滤波融合，输出俯仰、横滚、偏航姿态角
- PID控制任务：串级PID运算，输出四路电机PWM占空比（高优先级，保证控制实时性）
- 遥控接收任务：解析接收机摇杆指令，输出期望姿态、油门指令
- 状态上报任务：姿态、PWM输出状态通过串口上报上位机VOFA+波形观测

## 技术栈
STM32F4、FreeRTOS、MPU6050、I2C、互补滤波、串级PID、PWM输出、无线接收机

## 核心功能
1. MPU6050原始陀螺仪、加速度计数据读取，传感器零偏校准。
2. 互补滤波融合加速度、陀螺仪数据，解算飞行器俯仰、横滚、偏航姿态。
3. 串级PID控制：外层角度环输出目标角速度，内层角速度环输出电机PWM。
4. 接收遥控油门、姿态指令，输出四路PWM控制四路无刷电机。
5. 解决高速飞行机体剧烈震荡故障，实现飞行器稳定悬停。

## 关键难点与解决方案
1. **传感器噪声大，姿态解算抖动**
陀螺仪有温漂，加速度计振动噪声大；采用互补滤波做数据融合，调节滤波系数，抑制噪声同时保证姿态响应速度；上电做传感器零偏校准。

2. **高速飞行机体剧烈震荡**
现象：起飞后飞行器高频震荡，无法稳定悬停。
排查：①PID内环参数过大；②姿态解算任务、PID控制任务优先级分配不合理，高耗时运算抢占中断，控制周期不稳定。
解决：调小角速度环PID增益；提升PID控制任务优先级，保证控制周期固定；限制PWM输出上下限，防止电机输出饱和。

3. **控制周期不稳定带来控制效果恶化**
PID运算依赖固定周期；把PID任务设置较高优先级，避免被低优先级任务抢占，保证闭环周期稳定。

4. 电机输出饱和，PID积分累积
增加积分限幅、输出限幅，抑制积分饱和。

## 项目成果
完成从传感器读取‑姿态解算‑串级PID闭环‑电机驱动完整飞控原型；解决机体高速震荡故障，飞行器可以实现稳定悬停。
