# 四轴无人机飞控系统详细设计文档
## 1 需求概述
### 1.1 功能需求
1. 通过I2C读取MPU6050六轴传感器，完成陀螺仪、加速度计原始数据采集，上电零偏校准。
2. 姿态解算：互补滤波融合传感器数据，输出俯仰pitch、横滚roll、偏航yaw姿态角。
3. 接收遥控接收机输入：油门、俯仰、横滚、偏航期望指令。
4. 串级PID算法，角度环作为外环，角速度环作为内环，输出四路PWM，驱动四路无刷电机电调。
5. 串口上报姿态、PWM输出，VOFA+上位机观测调试波形。

### 1.2 非功能需求
1. PID闭环周期尽量稳定，保证控制实时性；
2. 抑制传感器噪声，姿态输出平滑；
3. 抑制震荡，实现飞行器稳定悬停；
4. 防止PID积分饱和，电机输出限幅保护。

## 2 硬件设计
1. 主控：STM32F4
2. 传感器：MPU6050，I2C接口；陀螺仪、加速度计。
3. 执行机构：4路TIM输出PWM信号，驱动无刷电调与无刷电机。
4. 遥控接收机：捕获PWM摇杆信号，获取遥控器输入。

> 注意：MPU6050注意供电稳定，电源噪声会直接引入传感器噪声。

## 3 软件总体设计
基于FreeRTOS多任务架构

|任务|优先级|功能说明|
|----|------|--------|
|pid_ctrl_task|最高|串级PID运算，输出四路电机PWM；固定闭环周期|
|attitude_solve_task|高|读取MPU6050，互补滤波姿态解算，输出姿态角|
|remote_task|中|解析遥控接收机摇杆，解析期望油门、姿态指令|
|report_task|低|串口上报姿态、PWM数据，上位机波形调试|

### 3.1 MPU6050采集与校准模块
1. I2C读取加速度、陀螺仪原始数据。
2. **上电静止校准**：采集多组陀螺仪静止数据，求取偏移，消除陀螺仪零偏。
> 重要：校准阶段飞行器必须保持静止，否则零偏参数错误，姿态完全错乱。

### 3.2 互补滤波姿态解算
- 加速度计：静态角度准确，动态振动噪声大；
- 陀螺仪：动态响应快，但是存在积分温漂；
互补滤波做加权融合，平衡二者优缺点，输出roll/pitch/yaw姿态。

### 3.3 串级PID控制逻辑
> 外环：角度环，输入期望角度与实际姿态角度误差，输出目标角速度；
> 内环：角速度环，输入目标角速度与陀螺仪实际角速度误差，输出电机PWM输出量。

1. 遥控器输出期望姿态角度、油门。
2. 角度PID（外环）：角度误差计算，输出目标角速度。
3. 角速度PID（内环）：角速度误差计算，输出控制量。
4. 四轴电机混控分配，把控制量分配到四个电机；叠加基础油门。
5. PWM输出限幅，防止输出饱和；PID开启积分限幅抑制积分饱和。

### 3.4 遥控信号解析
捕获接收机PWM脉冲宽度，解析摇杆输出；对摇杆输入做软件滤波，消除遥控抖动。

## 4 踩坑与问题记录（面试高频）
1. **飞行器起飞高频剧烈震荡，无法悬停**
现象：上电电机转动，机体高频抖动震荡。
排查步骤：
①读取姿态波形，确认姿态解算是否抖动；
②检查PID内环（角速度环）增益过大；
③检查任务优先级：PID闭环任务被低优先级任务抢占，闭环周期不稳定。
解决：调小角速度环P参数；提升pid_ctrl_task任务优先级，保证闭环周期稳定；增加PWM输出限幅。

2. MPU6050没有做零偏校准，姿态持续漂移
现象：飞行器静止，姿态角自己持续偏移。
解决：上电静止状态采集陀螺仪偏移做补偿校准。

3. 加速度计受振动干扰，姿态解算抖动
现象：电机转动振动传递到板子，加速度计输出乱跳，姿态抖动。
解决：互补滤波调整融合系数，降低动态下加速度计权重；硬件增加减震泡棉隔离振动。

4. PID积分饱和，飞行器大幅度超调
现象：大角度扰动后，回中动作过猛。
解决：角度环、角速度环全部开启积分限幅，输出做限幅。

5. I2C通信偶尔丢失MPU6050数据，姿态跳变
现象：姿态角偶尔跳变，飞行器瞬间失控。
解决：增加I2C通信错误判断；通信失败丢弃本次采样，不参与姿态解算。

## 5 测试结果
1. MPU6050零偏校准正常，互补滤波输出姿态平滑。
2. 串级PID闭环运行稳定，解决机体高速震荡故障。
3. 接收遥控指令，四轴飞行器原型可以稳定悬停；VOFA+可以观测完整姿态、PID输出波形。

## 6 扩展优化方向
1. 增加高度计，实现定高模式；
2. 增加位置GPS模块，实现定点飞行；
3. 增加故障保护逻辑，失控保护；
4. 移植姿态解算算法（卡尔曼滤波）做对比。
