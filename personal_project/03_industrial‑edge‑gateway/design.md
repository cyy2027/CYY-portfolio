# 工业物联网边缘网关详细设计文档
## 1 需求概述
### 1.1 功能需求
1. ESP32‑S3终端节点：采集传感器温湿度等数据，上报边缘网关；接收网关下发控制指令，执行输出动作。
2. RK3568边缘网关：
    - 部署本地MQTT Broker，接收多终端上报消息，支持设备Topic隔离。
    - SQLite数据库实现断网持久缓存，网络恢复自动补发历史数据。
    - 提供TCP‑Socket备用通信链路，处理大报文指令，自定义帧协议，CRC校验。
    - Web服务读取数据库，提供网页看板展示实时与历史时序数据。
3. 端‑边联调，支持多终端并发接入。

### 1.2 非功能需求
1. 网络断线时数据不能丢失，断电缓存数据不丢失；
2. 处理TCP粘包、半打开连接异常；
3. 多线程访问数据库安全，避免锁冲突崩溃；
4. 设置缓存上限，防止数据库持续膨胀占满存储。

## 2 硬件平台
1. 采集终端：ESP32‑S3，Wi‑Fi通信，外接传感器模块。
2. 边缘网关：RK3568 Linux开发板，千兆以太网，运行Mosquitto MQTT Broker。

## 3 总体软件架构
### 3.1 ESP32‑S3（FreeRTOS）软件模块
|任务|优先级|功能|
|---|---|---|
|sensor_collect_task|中|周期读取传感器，组装JSON报文|
|mqtt_net_task|高|MQTT客户端，指数退避断线重连，发布上报报文，订阅控制Topic|
|cmd_handle_task|中|解析网关下发JSON控制指令，执行IO动作，回传执行状态|

MQTT Topic约定
- 设备上报：`device/{dev_id}/upload`
- 网关下发控制：`device/{dev_id}/cmd`

上报JSON报文示例
```json
{
  "dev_id": "esp32_01",
  "temp": 24.8,
  "hum": 61.3,
  "timestamp": 1750000123
}
