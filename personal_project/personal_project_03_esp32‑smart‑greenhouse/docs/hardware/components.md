# ESP32智能温室大棚系统 — 元器件选型文档
## 📌概述
本系统面向小型温室、家庭种植场景，遵循**低成本、高稳定性、易采购、易维护**选型原则。整套硬件物料合计 **40.9元**，全部为市面通用模块化器件，无小众特殊物料。

## 一、主控方案对比
对比3种可行主控通信方案，从成本、开发难度、外设资源、使用场景综合评估。

|方案|主控|通信方式|优点|缺点|是否选用|
|---|---|---|---|---|---|
|A方案|STM32F103C8T6|4G模块|不依赖WiFi，适合野外无网络场景|硬件成本高；需要额外4G流量；开发工作量大|❌不选用|
|B方案|ESP8266‑01S|WiFi|价格低廉，开源资料丰富|外设IO资源紧张，难以同时驱动多传感器+OLED+多路执行器，扩展性差|❌不选用|
|C方案|ESP32‑WROOM‑32(CH340，Type‑C)|2.4G‑WiFi|双核处理器性能充足；自带WiFi蓝牙；外设资源丰富；Arduino生态成熟；成本可控；可同时驱动全部外设|仅支持2.4G WiFi，无法在无WiFi环境工作|✅**最终选型**|

> 选型结论：选择C方案 ESP32‑WROOM‑32，兼顾开发效率、外设资源与硬件成本，满足本项目单节点温室监测控制全部需求。

## 五、硬件设计注意要点
1. 继电器模块带光耦隔离，实现强弱电隔离，避免高压侧干扰损坏ESP32主控；
2. DHT11为单总线器件，建议外部增加上拉电阻保证通信稳定性；
3. BH1750与OLED共用同一组I2C总线，确认I2C器件地址无冲突；
4. WiFi仅支持**2.4G频段，5G WiFi无法连接阿里云；
5. 土壤湿度选用电容式，规避电阻式电极腐蚀老化的问题；
6. 所有模块统一3.3V/5V供电，严格核对电源电压，防止器件烧毁。
