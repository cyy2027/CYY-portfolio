# 北斗/GNSS 定位飞控系统｜实时控制与空间定位
> 全链路飞控系统开发｜2026.07–2026.10

## 🛠 技术栈
STM32H723/F405 | FreeRTOS | C/C++ | Qt5  
IMU/GNSS/气压计多传感器融合 | 串级PID姿态控制  
Dshot-600数字电调 | ELRS(CRSF)遥控遥测  
MSP OSD数据叠加 | IRC Tramp图传协议 | ESP8285 Wi-Fi透传上位机

## 📌 项目简介
本项目从零搭建**多旋翼GNSS定点飞控完整系统**，采用STM32主控+ESP8285无线辅助的双芯片架构。
底层实现高精度IMU姿态解算、多传感器数据融合、串级PID姿态/高度/位置闭环；中层完成Dshot高频电机驱动、远距离ELRS遥控链路、MSP OSD图传数据叠加；上层基于Qt5开发跨平台上位机，实现可视化调参与实时数据监控，打通飞控从感知、控制、驱动到无线交互的完整工程链路。

## ✨ 核心项目亮点
### 1. 多源传感器融合 + 四级串级PID闭环
基于 ICM-42688-P 高精度IMU、气压计、M10北斗/GNSS模组完成多源数据融合。
搭建**角度环-角速度环-高度环-位置环**四级串级PID，实现自稳、定高、GNSS定点悬停功能，有效抑制机身漂移与姿态震荡。

### 2. 高速Dshot-600数字电调驱动开发
自研Dshot-600高速数字驱动协议，相比传统PWM，具备**更高刷新率、抗干扰强、无死区**优势，实现电机毫秒级精准调速，提升飞行器动态响应与稳定性。

### 3. 远距离无线通信链路完整适配
移植并适配 **ELRS(CRSF)** 协议栈，实现超远距离低延迟遥控指令接收与机载状态遥测回传；
移植 **IRC Tramp 图传控频协议 + MSP OSD**，将姿态、高度、位置、电量数据实时叠加至图传画面。

### 4. 双芯片协同架构（STM32+ESP8285）
主控负责高强度实时控制，ESP8285独立承担Wi-Fi无线透传、参数在线调参、数据转发任务，**解耦控制业务与无线业务**，保证飞控底层控制时序绝对稳定。

### 5. Qt5跨平台可视化上位机
独立开发桌面/安卓双端GUI上位机，支持传感器波形可视化、PID参数在线一键修改、飞行数据记录、设备状态监控，大幅提升飞控调试效率。

## 🎯 项目成果
完整搭建 **传感器融合 → 串级PID姿态位置闭环 → Dshot高速电机驱动 → ELRS无线遥控遥测 → OSD图传叠加 → Wi-Fi无线调参上位机** 全链路飞控系统。
熟练掌握嵌入式高速协议、多传感器融合、多级闭环控制、实时系统调度、跨芯片协同架构，具备大型实时控制类产品完整开发能力。
