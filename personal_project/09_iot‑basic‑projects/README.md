# 物联网与消费电子综合实践
## 项目简介
本工程集合三套物联网基础原型项目，分别为**离线语音蓝牙音箱、ESP32智能温室大棚、STM32心电采集监测仪**。
覆盖音频SoC开发、MQTT物联网上云、微弱生物信号采集三大方向，验证外设驱动、事件回调、DMA高速采样、断线重连、参数掉电保存等嵌入式基础能力。

### 子工程说明
1. **offline_voice_speaker｜离线语音蓝牙音箱**
基于杰理Byle‑U8音频SoC，实现A2DP蓝牙音频播放、离线KWS语音唤醒识别；支持语音、AD按键、红外遥控器三路输入控制WS2812彩灯。

2. **smart_greenhouse｜ESP32智能温室大棚**
ESP32采集温湿度等环境传感器数据，对接阿里云IoT MQTT平台；实现APP远程控制、阈值自动调控，EEPROM保存配置参数，具备Wi‑Fi断线自动重连。

3. **ecg_monitor｜心电采集监测仪**
基于STM32+AD8232心电放大模块，搭建三层软件架构；DMA+ADC高速采集人体心电微弱模拟信号，串口上报Python上位机绘制心电波形。

## 技术栈
杰理Byle‑U8 SDK、ESP32‑Arduino、STM32 HAL库、A2DP蓝牙、离线KWS、MQTT、阿里云IoT、ADC/DMA、UART空闲中断、EEPROM、AD8232生物传感器

## 核心功能
### 离线语音蓝牙音箱
1. A2DP蓝牙音频，手机蓝牙音乐播放。
2. 离线KWS离线语音唤醒，自定义语音控制指令。
3. AD分压按键、红外遥控器、语音三路输入事件统一处理。
4. WS2812 RGB彩灯控制，不同指令切换灯光效果。

### ESP32智能温室大棚
1. 环境传感器采集温湿度，OLED本地实时显示。
2. MQTT对接阿里云IoT，数据上报云端，支持APP下发远程控制指令。
3. 阈值自动调控逻辑，环境超标自动执行外设动作。
4. EEPROM保存阈值配置参数，断电不丢失；Wi‑Fi断线自动重连，保障无人值守稳定运行。

### STM32心电采集监测仪
1. 驱动AD8232模拟前端，采集人体微弱心电信号。
2. DMA搬运ADC采样数据，定时器控制采样节拍，实现高速不间断采样。
3. UART空闲中断解析上位机指令，支持修改采样率、采集时长参数。
4. 分层软件架构：驱动层‑业务层‑调试层，条件编译裁剪调试模块；串口上报原始波形给Python上位机绘图。

## 关键难点与解决方案
1. **离线语音音箱多路输入（语音/按键/红外）事件冲突**
三路输入会同时触发；设计事件回调队列，统一事件分发，避免多输入冲突，防止重复执行动作。

2. **ESP32 Wi‑Fi网络抖动，设备离线丢失数据**
实现MQTT指数退避重连机制；检测网络断开自动重连，保障长期无人值守运行。

3. **心电属于毫伏级微弱信号，噪声干扰大，波形杂乱**
AD8232模拟前端做好硬件滤波；软件做滑动平均滤波，抑制工频噪声，提取有效心电波形。

4. **ADC采样CPU占用高**
采用DMA搬运ADC采样结果，CPU不需要介入每一次采样，减轻CPU负担。

## 项目成果
- 离线语音音箱：蓝牙音频播放可用，离线语音识别生效，三路输入统一控制彩灯。
- 智能温室：完成端云双向闭环，阈值自动调控，参数断电保存，断线自动重连。
- 心电采集仪：高速采集心电信号，上位机可以正常绘制心电波形；软件分层架构可裁剪调试模块。
