## 概述
ADC是嵌入式模拟信号采集核心外设，用于电压、电流、温度等模拟量测量。ADC采集精度不单单取决于芯片本身，硬件前端电路、采样时序、电源噪声都会严重影响结果。
本文从硬件前端、采样架构、校准、软件滤波、故障排查完整梳理工程方案，重点讲解FOC电机PWM同步电流采集、充电桩母线电压采集场景。
## 覆盖能力
- 12bit ADC基础原理，参考电压VREF选型
- 分压、RC低通滤波、输入钳位保护硬件电路设计
- DMA连续扫描 + PWM同步触发ADC（FOC电流采集经典方案）
- 双缓冲采样架构，避免读取半更新数据
- 滑动平均、中值滤波、一阶低通滤波软件算法
- ADC偏移+增益两点校准方法
- 多路通道串扰、输入阻抗不足、电源纹波等问题排查
- DMA缓冲区内存约束、栈内存使用禁忌
## 一、ADC基础原理
1. 分辨率：STM32/AT32内置ADC大多为12bit，采样范围 `0 ~ 4095`。
计算公式：`V_in = adc_raw * VREF / 4095`
2. VREF参考源：内部参考简单但温漂大；外部基准TL431等精度更高，适合高精度采集。
3. 采样周期：采样保持时间 + A/D转换时间；采样时间太短会导致采集值偏低，多路通道切换会产生通道串扰。
4. 两种采集架构：软件轮询采集、DMA连续扫描采集。工程中高速采集优先DMA扫描。

## 二、硬件前端电路设计
1. 电阻分压：高压信号通过电阻分压降到ADC量程以内。需要考虑功率与输入阻抗。
2. RC低通滤波：ADC输入增加RC网络抑制高频噪声；**串联电阻建议≤10kΩ**，电阻过大会导致采样保持电容充电不足，读数偏小。
3. 钳位保护二极管：并联在ADC输入与GND/VREF之间，防止过压烧毁ADC通道。
4. 电源去耦：ADC模拟电源引脚就近放置0.1μF陶瓷电容，降低电源纹波噪声。

## 三、DMA+定时器同步采样（FOC电机电流采样）
方案：TIM定时器触发ADC连续转换，DMA循环搬运采样数据，实现**PWM中点同步采样电流**，降低PWM开关噪声。
```c
// ✅ 正确：全局静态数组作为DMA缓冲区
uint16_t adc_buf[2];
// ❌ 错误：局部栈数组，严禁用作DMA目标缓冲区
void adc_test(void)
{
    uint16_t buf[2];
}
```
- 双缓冲机制：A缓冲区DMA填充时，CPU处理B缓冲区数据，防止读到正在更新的半帧数据。
- 同步采样优势：在PWM载波中点采样，避开MOS开关瞬间尖峰噪声，电流波形更干净。

## 四、软件滤波算法
```c
// 一阶低通滤波
float adc_lowpass(float new_val, float old_val, float alpha)
{
    return old_val + alpha * (new_val - old_val);
}
```
1. 滑动平均滤波：连续N次采样取平均值，抑制随机尖峰噪声；缺点存在滞后。
2. 中值滤波：剔除最大最小值再求平均，适合偶发脉冲干扰。
3. 一阶低通滤波：适合缓慢变化信号（温度、母线电压）。

## 五、ADC校准
1. 芯片自校准：STM32 HAL库 `HAL_ADCEx_Calibration_Start()`，必须在ADC使能前调用，消除芯片内部偏移误差。
2. 两点工程校准：修正偏移与增益误差
    - 零点：输入0V，读取原始ADC值，作为offset偏移量
    - 满点：输入已知标准电压，计算增益系数gain
    最终电压：`V = (adc_raw - offset) * gain`

## 六、工程实测踩坑记录
1. DMA缓冲区定义为局部数组，存放在栈中，DMA改写栈内存，随机HardFault。
2. 采样周期设置太短，多路通道切换串扰，ADC数值持续跳动。
3. 前端RC串联电阻过大，采样电容充电不足，采样读数偏小。
4. 模拟电源缺少去耦电容，电源纹波大，ADC数值抖动严重。
5. FOC项目没有PWM同步采样，电流噪声大，电机抖动。
6. VREF使用内部基准，温度变化带来明显温漂，电压采集随温度漂移。
7. 长线采集信号，没有差分处理，引入外部电磁干扰。

## 七、适用项目场景
- STM32 FOC无刷电机项目：PWM同步ADC+DMA三相电流采样、双缓冲数据处理
- 智能充电桩项目：母线电压、输出电流采集，分压保护与软件滤波
- 八路电源时序器：多路电压监测、过压欠压检测
