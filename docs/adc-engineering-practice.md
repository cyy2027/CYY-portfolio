
# ADC工程实践
> 文档位置：`docs/tech-notes/adc-engineering-practice.md`
>
> 说明：本文为项目开发整理的ADC采集工程方案与踩坑记录，**非完整工程源码**，案例来源于FOC电机、智能充电桩项目。

## 1. ADC采样基础与时序要点
1. 分辨率：STM32/AT32内置ADC多为12bit，采样数值范围 `0 ~ 4095`；采样结果 = `(输入电压 / VREF) × 4095`。
2. 采样周期：采样保持时间 + 转换时间；采样周期不足会导致采样精度下降。
3. 参考电压VREF：可以使用内部参考源或外部基准；外部基准稳定性更好，适合高精度采集。
4. 多通道采集两种方案：轮询依次转换、DMA连续扫描（工程优先推荐DMA扫描）。

## 2. DMA循环采样工程方案（FOC电机电流采样）
1. 配置ADC为**连续转换模式 + DMA循环搬运**，自动循环采集多通道电压/电流，CPU无需介入搬运。
2. DMA缓冲区限制：**不能使用局部数组作为DMA目标缓冲区**，局部数组存放在栈中，极易出现内存异常。必须定义全局/静态数组。
```c
// ✅ 正确：全局数组
uint16_t adc_buf[2];
// ❌ 错误：局部数组，不可用于DMA
void adc_test(void){
    uint16_t buf[2];
}
```

3. 双缓冲机制：设置两组采样缓冲区，DMA 填充 A 区时 CPU 处理 B 区数据，避免采样过程中读取半更新的数据。
4. 触发方式：TIM 定时器触发 ADC，实现和 PWM 同步采样，FOC 电机在 PWM 中点采样电流，降低噪声。

## 3. 模拟前端硬件电路

1. 分压电路：高压信号通过电阻分压降低至 ADC 输入量程。
2. RC 低通滤波：在 ADC 输入增加 RC 滤波，抑制高频噪声；电阻不能过大，否则输入阻抗不足，影响采样精度。
3. 保护电路：输入端并联钳位二极管，防止电压超过 VREF 或低于 GND，避免烧毁 ADC 通道。

> 
> 工程经验：ADC 输入引脚阻抗建议控制在 10kΩ 以内。

## 4. 采样误差来源

1. 输入阻抗不匹配：前端电阻过大，采样保持电容充电不充分，采样值偏小。
2. 基准电压漂移：内部 VREF 受温度影响大，温漂会带来采集偏差。
3. 电源噪声：MCU 电源纹波直接叠加到 ADC 参考源，造成数值跳动。
4. 串扰：多路 ADC 相邻通道切换带来串扰误差，需要增加足够采样保持时间。

## 5. 软件滤波算法

1. 滑动平均滤波：取 N 次采样做平均值，抑制随机噪声，简单易实现，缺点有滞后。
2. 中值滤波：去掉最大最小值再取平均，适合剔除尖峰脉冲干扰。
3. 一阶低通滤波：适合缓慢变化信号（温度、电压），抑制高频噪声。

```
// 一阶低通滤波示例
float adc_lowpass(float new_val, float old_val, float alpha)
{
    return old_val + alpha * (new_val - old_val);
}
```

## 6. ADC 校准

1. 芯片内置自校准：STM32 使用`HAL_ADCEx_Calibration_Start()`，必须在 ADC 使能前执行，消除内部偏移误差。
2. 工程两点校准：采集零点与满点，修正增益误差 + 偏移误差。
   - 零点：输入 0V，读取 ADC 原始值 offset
   - 满点：输入已知标准电压，计算增益系数

## 7. 高频踩坑汇总

1. DMA 缓冲区放在栈内 → 随机 HardFault、采样数据错乱。
2. 采样周期设置太短，通道切换串扰，数值跳动。
3. 前端 RC 电阻太大，ADC 采样保持电容充不满，读数偏低。
4. 电源纹波大，没有增加去耦电容，ADC 采样持续抖动。
5. FOC 项目未同步 PWM 采样，电流采样噪声大，电机抖动。
