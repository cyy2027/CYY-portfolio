# 无感 FOC 转子位置观测器：滑模观测、PLL 提取与低速高频注入

> 📄 文档路径：`docs/sensorless-foc-observer.md`

> ✍️ 面向电机控制岗的专题梳理：把"去掉位置传感器"这件事拆成三块 —— 反电动势观测（中高速）、高频注入（零低速）、两者之间的切换与启动强拖。含滑模观测器推导、PLL 角度提取、离散化实现、参数敏感性的量级估算与常见失效排查。

> ⚠️ **文档定位**：观测器部分为**理论推导 + 代码骨架 + 参数敏感性分析**，尚未在实物上闭环。原因写在第九节：03 项目的硬件没有相电流采样电路，而基于反电动势的观测器全部要用「实测电流 − 估计电流」构造误差项 —— 缺的是必要输入，不是调参问题。已在实物上跑通的电压模式 FOC 链路见[《无电流采样下的 FOC 电压模式控制实践》](./motor‑foc‑control.md)。

## 概述

FOC 需要实时电角度。编码器给角度，但要成本、要线束、要装配空间，还会在粉尘、油污、强振动、密封场合失效。无感（sensorless）就是用电压和电流反推角度。

有一个误解值得先澄清：**「无电流采样」和「无位置传感器」是两件不同的事，方向甚至相反。**

| | 去掉电流采样 | 去掉位置传感器 |
|---|---|---|
| 期望收益 | 省采样电阻、运放、ADC 通道 | 省编码器 / 霍尔及其线束 |
| 代价 | 失去电流闭环，转矩不可控、无法限流 | 失去角度基准，需要观测器 |
| 对硬件的要求 | **更低** | **更高**：观测器必须有相电流 |

观测器的误差源就是电流误差，没有电流就没有误差信号。所以无感方案反而比电压模式 FOC 需要更完整的采样链路。选型阶段就要说清楚这一点，否则会出现「既要省电流采样、又要无感」的矛盾需求 —— 这类需求在评审会上必须当场挡回去。

### 覆盖内容

- 从 αβ 电压方程看反电动势三个可读性质，理解观测器到底在分离什么
- 滑模观测器（SMO）设计：到达条件、抖振抑制、低通相位补偿
- PLL 角度提取：为什么不用 `atan2`，环路参数怎么定
- `atan2` / 滑模 / 龙伯格 / 磁链积分 / 扩展 EMF / 高频注入六种方案的取舍表
- 低速盲区的成因与量级估算（含一个可复算的算例）
- 启动强拖（I-F）与切换判据，切换失败的三类典型现象
- 离散化稳定性、采样时序、死区补偿、ADC 零漂等实现要点，附失效模式速查表

## 一、被观测量：反电动势

表贴式 PMSM（Ld = Lq = L）在 αβ 静止坐标系下的电压方程：

```text
uα = R·iα + L·diα/dt + eα
uβ = R·iβ + L·diβ/dt + eβ

eα = -ωe·ψf·sin(θe)
eβ =  ωe·ψf·cos(θe)
```

从这个式子能直接读出三件事：

1. **e 的幅值正比于转速**（`|e| = ωe·ψf`）。高速信噪比好，低速塌陷 —— 这是所有反电动势类方法的能力边界，不是算法优劣问题。
2. **e 的相位含 θe**。理论上 `θe = atan2(-eα, eβ)` 一步到位。
3. **e 与电流无关**，只跟转速和磁链有关。所以观测器的本质工作是：从「已知的电压」和「测到的电流」里，把 e 这个未知项分离出来。

直接把 `atan2` 套上去能用，但问题明显：每个周期独立计算、不利用历史信息、噪声全额传导到角度上。实际工程几乎都会在后面接一个 PLL。

## 二、滑模观测器（SMO）

### 2.1 结构

用测量电流驱动一个电流观测器，把误差用符号函数压到滑模面：

```text
d(îα)/dt = (1/L)·(uα - R·îα - k·sgn(îα - iα))
d(îβ)/dt = (1/L)·(uβ - R·îβ - k·sgn(îβ - iβ))
```

滑模面 `s = î - i`。当增益 k 大于反电动势幅值的上界（`k > |e|max`），状态在有限时间内到达 s = 0，此后符号项的高频切换**等效值**就等于反电动势：

```text
k·sgn(s) → e   （等效控制量）
```

于是「求解 e」变成「滤出符号项的平均分量」，观测器设计问题转化为滤波器设计问题。

### 2.2 抖振：不能直接用 sign

理想符号函数在离散实现里会以采样频率反复翻转，产生抖振。抖振的后果不只是电流噪声 —— 它会通过观测角度进入 Park 变换，形成

> 角度抖动 → 转矩脉动 → 转速波动 → 角度抖动

这样的闭环，低速时可能自激。三种工程替代：

| 替代方案 | 做法 | 代价 |
|---|---|---|
| 饱和函数 | 边界层内线性：`sat(s/φ)` | 边界层内失去滑模不变性，稳态有偏差 |
| 平滑函数 | `tanh(λs)` 或 sigmoid，连续可导 | 到达时间变长，需要重新整定 k |
| 自适应增益 | k 随转速上升而增大 | 多一层调度逻辑，切换点要防抖 |

低转速时用较小的 k 压抖振，高转速时 e 变大、必须用更大的 k 才能满足到达条件 —— 这是自适应增益的动机，也是它容易做出问题的原因：如果 k 跟不上转速，观测器会在加速过程中"掉出"滑模面，表现为加速到某个转速突然失锁。

### 2.3 低通滤波与相位补偿

等效控制量里混着采样频率附近的高频分量，必须低通。一阶 LPF：

```text
ê = LPF(k·sgn(s)),   H(s) = ωc / (s + ωc)
```

代价是相位滞后。在电角频率 ωe 处：

```text
Δθ = arctan(ωe / ωc)
```

必须补偿回来：`θ̂_comp = θ̂ + Δθ`。

这里有个容易被忽略的循环依赖：**Δθ 依赖 ωe，而 ωe 本身是估出来的**。低速时 ωe 的相对误差大，补偿量算不准，"补偿"反而成为新的误差源。这是「低速不适合 EMF 法」的第二个理由（第一个是幅值塌陷）。

ωc 的经验取值：1~3 倍最高电角频率。取太低滤波干净但补偿角大、对转速估计敏感；取太高补偿量小但高频分量漏过来，PLL 输入抖。

### 2.4 代码骨架

```c
/* 10 kHz，PWM 中断内执行；float 版本，M4F 及以上可直接用 */
typedef struct {
    float R, L, Ts;
    float k;              /* 滑模增益，需 > |e|max */
    float phi;            /* 饱和函数边界层厚度 */
    float i_hat_a, i_hat_b;
    float e_a, e_b;       /* 低通后的反电动势估计 */
    float wc;             /* LPF 截止频率 rad/s */
} smo_t;

static inline float sat(float x, float phi)
{
    if (x >  phi) return  1.0f;
    if (x < -phi) return -1.0f;
    return x / phi;
}

void smo_update(smo_t *s, float u_a, float u_b, float i_a, float i_b)
{
    float err_a = s->i_hat_a - i_a;
    float err_b = s->i_hat_b - i_b;

    /* 电流观测器：前向欧拉离散 */
    s->i_hat_a += s->Ts / s->L * (u_a - s->R * s->i_hat_a - s->k * sat(err_a, s->phi));
    s->i_hat_b += s->Ts / s->L * (u_b - s->R * s->i_hat_b - s->k * sat(err_b, s->phi));

    /* 等效控制量一阶低通，离散形式：y += (Ts*wc)*(x - y) */
    float z_a = s->k * sat(err_a, s->phi);
    float z_b = s->k * sat(err_b, s->phi);
    s->e_a += s->Ts * s->wc * (z_a - s->e_a);
    s->e_b += s->Ts * s->wc * (z_b - s->e_b);
}
```

### 2.5 离散化是第一个大坑

`Ts/L` 这一项决定前向欧拉的稳定性。举两个真实量级：

- L = 1.2 mH，Ts = 100 µs → `Ts/L ≈ 0.083`，配合 R 项，前向欧拉可用；
- L = 200 µH（空心杯 / 小电感电机），Ts = 100 µs → `Ts/L = 0.5`，前向欧拉在电流环带宽附近就会振荡发散。

现象很典型：**上电几毫秒内观测电流指数发散到饱和，输出电流瞬间顶到限幅**。新手常误判成"参数填错"，实际是离散化格式不对。三条出路：

1. 换双线性（Tustin）离散，稳定性边界好很多；
2. 观测器降采样率跑（例如 PWM 10 kHz、观测器 5 kHz），代价是相位滞后增加；
3. 用精确离散化（矩阵指数），计算量大，一般在定点平台才值得。

## 三、PLL 角度提取

把 êα、êβ 当作含噪的 sin/cos，用锁相环锁相：

```text
ε = -êα·cos(θ̂) - êβ·sin(θ̂)    ∝  sin(θe - θ̂)
ω̂ = Kp·ε + Ki·∫ε
θ̂ = ∫ω̂ dt
```

把 `ê = ωe·ψf·(-sin θe, cos θe)` 代入，展开后 ε 正好等于 `ωe·ψf·sin(θe − θ̂)`。小角度下近似线性：

```text
ε ≈ ωe·ψf·(θe - θ̂)
```

所以 PLL 把角度误差线性化成一个比例环节，Kp / Ki 就是标准二阶环路参数，可以按阻尼比和带宽来设计，不用瞎试。

### 比 atan2 好在哪

- **输出连续**，带惯性，噪声被环路带宽压掉，而不是全额传导；
- **直接给出 ω̂**，省掉对角度做差分求速度（差分放噪是另一个经典坑）；
- **可按带宽设计**，把环路带宽和机械时间常数对齐，动态可预期。

### 代价

- 环路带宽低 → 突加负载时角度滞后，恢复慢；
- 启动阶段存在 `θ̂` 与 `θe` 相差 180° 的伪平衡点。理论上它不稳定，但强噪声下可能短暂停留，表现为转向判断错误 —— 需要在首次收敛时做一次方向校验（比对指令转向与 ω̂ 符号）。

## 四、六种方案的取舍

| 方法 | 零低速 | 中高速 | 参数敏感性 | 计算量 | 适用判断 |
|---|---|---|---|---|---|
| `atan2` 直接反算 | 差 | 可 | 高 | 极低 | 快速验证、台架调试 |
| 滑模观测 SMO | 差 | 好 | 中（L、R） | 中 | 通用首选，鲁棒性好 |
| 龙伯格观测器 | 差 | 好 | 中 | 中 | 线性区、需要按极点配置调 |
| 磁链积分观测 | 中 | 好 | **低**（对 R 敏感，但可补偿） | 低 | 成本敏感、要求稍低转速 |
| 扩展 EMF（EEMF） | 中 | 好 | 中 | 中 | 凸极率大的 IPM |
| 高频注入 HFI | **好** | 差 | 低（依赖凸极） | 中高 | 零低速、必须带载启动 |

补充两点：

**磁链积分观测器**：`ψ = ∫(u − R·i)dt`，角度 `atan2(ψβ − L·iβ, ψα − L·iα)`。纯积分有直流漂移和初值问题，工程上要么加高通（引入相位误差），要么做「电压模型 + 电流模型」混合 —— 低速用电流模型保证收敛，高速切电压模型保证精度，中间加权过渡。混合方案本质上是把 HFI 和 EMF 的切换问题换了个位置，复杂度没有消失。

**高频注入（HFI）**：给 d 轴注入高频电压（旋转注入或脉振注入），凸极电机（Ld ≠ Lq）的响应电流幅值随转子位置呈 2θe 周期变化，同步解调后提取位置。表贴式电机凸极率太低，HFI 效果差 —— 这时要么靠注入 d 轴电流人为制造饱和凸极，要么老实装编码器。

## 五、低速为什么必须换一条路

`|e| = ωe·ψf`。转速降到额定的 5%，e 只剩 5%；而 Rs 误差、死区、ADC 零漂造成的电压误差**不随转速下降**。信噪比直接崩掉。

做一个可复算的量级估算。取一台小云台电机：ψf = 0.0035 Wb，R = 0.75 Ω，额定相电流 1.5 A。

| 项 | 数值 | 说明 |
|---|---|---|
| ωe = 100 rad/s 时的 e 幅值 | 0.35 V | `ωe·ψf` |
| 温升 80 ℃ 的电阻增量 | 约 0.22 Ω | 铜电阻温度系数 0.4 %/℃，`0.75 × 0.3` |
| 该电阻误差造成的电压误差 | 约 0.33 V | `ΔR·i = 0.22 × 1.5` |

误差和信号同量级。最坏情况（电压误差全落在与 EMF 正交的方向上）角度误差 `asin(0.33 / 0.35) ≈ 70°`；即便只有一半落在正交方向，也有 40° 量级 —— 磁场定向已经不可用，电机表现为抖动、转矩大幅下降甚至反转。

这个估算的结论比数字本身更重要：**低速误差不是"调参能救"的，是模型在该工作点失效**。所以低速只有两条路：

1. 在线辨识 Rs（注入已知直流，测电压电流反算电阻），把 ΔR 压下去；
2. 换一条不依赖反电动势的观测路径，即高频注入。

## 六、启动：I-F 强拖与切换

无感最大的坑不在稳态，在启动。静止时 ωe = 0 → e = 0 → 观测器没有任何输入，必须先用开环把转速拖起来。

**I-F 升频升流流程**：

1. 固定电流幅值（或固定 V/f 比），频率从 0 按斜坡上升；
2. 转子被"拖着"同步旋转，此时角度由开环给定，不是观测出来的；
3. 转速升到观测器可用的下限（经验值：额定的 10~15%，且 e 幅值 ≥ 5 倍误差量级）；
4. 把角度源从开环切到观测器，同时电流环从开环切到闭环。

**切换判据，三个条件缺一不可**：

- 转速够（e 幅值够，观测器有信噪比）；
- 角度差小（观测角与开环角之差 < 阈值，取 15° 左右）；
- 持续满足（连续 N 个周期都满足才切，防止单次噪声误触发）。

切早了，观测器还没收敛，角度跳变 → 电流冲击 → 可能反转。切晚了，I-F 段效率低、发热大、负载突变容易失步。

更平滑的做法是**角度渐渡**：切换瞬间不让角度直接跳，而是在若干毫秒内用加权把 `θ_open` 过渡到 `θ_obs`，同时把电流给定从开环幅值过渡到闭环输出。代价是这段过渡里角度既不是开环的真值也不是观测值，需要保证过渡时间远小于机械时间常数。

## 七、工程实现要点

1. **采样时序**：电流必须在 PWM 中心对齐点采样，避开开关瞬间的振铃。单电阻母线采样还有重构盲区（占空比接近 0 或 100% 时无法重构三相电流），必须靠移相或最小脉宽限制规避。
2. **ADC 零漂**：上电静止时多次采样求平均做偏置校准；运行中温漂会让观测器产生持续偏移。磁链积分观测器对此最敏感 —— 积分会把一个毫伏级偏置累积成可观的角度误差。
3. **死区补偿**：死区造成的电压损失在低速占比很大，且随电流方向翻转，等效成一个符号随电流变化的误差电压。不补偿就等于持续给观测器喂错数据，低速抖动的常见根因就在这。
4. **参数随工况漂移**：R 随温度（0.4 %/℃），L 随电流饱和（IPM 尤其明显）。观测器里写死的 R、L 只是某一工况的值，要预留在线辨识或分段查表的接口。
5. **定点实现**：M0/M3 无 FPU，Q15 定点要注意中间量饱和；`atan2` 用查表 + 线性插值，表长与精度要权衡（1° 精度大约需要 90 点 + 象限处理）。

## 八、常见失效模式速查

| 现象 | 可能根因 | 先查什么 |
|---|---|---|
| 低速抖、高速正常 | EMF 信噪比不足 / 死区未补偿 / Rs 不准 | 静止注入测 R；示波器看相电流过零畸变 |
| 加速到某转速突然失锁 | 滑模增益跟不上转速 / LPF 截止频率过高 / PLL 带宽过大 | 打印 ω̂ 与给定转速的偏差曲线 |
| 上电几毫秒观测电流发散 | 离散化不稳定（Ts/L 过大） | 换双线性离散或降观测器采样率 |
| 启动反转 | I-F 初始角度错 / 切换过早 / 相序接反 | 先验证开环强拖能否稳定正转 |
| 切换瞬间电流冲击 | 角度跳变未做渐渡 | 记录切换前后 20 ms 的角度与 iq |
| 空载正常、带载失步 | 观测器带宽不够 / 电流环饱和 | 看 iq 是否顶到限幅 |
| 长时间运行角度缓慢漂移 | 磁链积分直流偏置 / ADC 零漂 | 对比观测角与编码器角（台架上） |

## 九、和现有平台的关系：要补什么才能落地

03 项目（[STM32 无刷电机 FOC 控制系统](../personal_project/03_foc‑bldc‑motor)）做的是**无电流采样**的电压模式 FOC，靠 AS5600 磁编码器拿角度。要在这套平台上跑观测器，缺三样东西：

1. **相电流采样电路** —— 双电阻下桥臂或单电阻母线，采样电阻 + 运放 + ADC 通道；
2. **与 PWM 同步的 ADC 触发** —— 定时器 TRGO 触发，保证在中心对齐点采样；
3. **电流环（PI）** —— 观测器的误差项在电流闭环下才有意义；纯电压模式做无感等于同时失去电流环和位置环，调试会变成盲调。

这三条不补，观测器没有输入。所以这篇文档停在「推导 + 骨架」，不包装成「实测数据」—— 没有数据就是没有数据。

想真正验证的话，成本最低的路径是买一块带三电阻采样的栅极驱动板（DRV8302 / DRV8316 一类方案），先把电流环和 `atan2` 版本的粗糙观测跑通，确认角度能跟上，再叠滑模和 PLL。顺序反过来（先上 SMO 再补电流环）基本调不出来，因为错在哪一层都分不清。
