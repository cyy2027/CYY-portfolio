# 无电流采样下的FOC电压模式控制实践
> 📄 文档路径：`docs/motor‑foc‑control.md`

> > ✍️ 个人实践总结：BLDC永磁同步电机FOC磁场定向控制；电压模式FOC实现，在无采样电阻、无电流传感器条件完成电机矢量控制；包含SVPWM生成、坐标变换(Clarke/Park/反Park)、角度观测、调参经验、硬件限制下的取舍与大量实测踩坑记录。

## 概述
常规FOC方案依赖相电流采样，通过ADC采集三相电流，经过Clarke、Park变换得到d/q轴电流，再使用双闭环（电流环+速度环）PID闭环控制。但部分低成本硬件没有电流采样电路，缺少运放、采样电阻，无法获取实时相电流。

**电压模式FOC（开环电流FOC）**：不采集实际相电流，直接输出d、q轴电压指令，依靠霍尔/编码器获取转子角度，完成磁场定向。牺牲部分动态性能，以硬件成本降低为目标，可实现电机平滑启动、调速、换向，适合风机、小型泵类等对动态响应要求不苛刻的场景。

本文梳理矢量控制完整链路：坐标变换、SVPWM算法实现、角度获取方案；对比有电流采样闭环与无采样电压模式差异；记录调参、启动抖动、失步、磁场定向错误等工程问题。

### 覆盖能力

- SVPWM空间矢量脉宽调制算法实现，过调制处理

## 一、FOC基础理论回顾
### 1.1 坐标变换
1. **Clarke变换**：三相静止ABC坐标系 → 两相静止α‑β坐标系
2. **Park变换**：两相静止α‑β → 两相旋转d‑q坐标系（跟随转子磁场旋转）
3. **逆Park变换**：d‑q电压指令转回α‑β静止坐标系，送入SVPWM生成PWM输出

> 常规电流闭环FOC流程：
> ADC采样三相相电流 → Clarke → Park → dq电流PID调节 → 逆Park → SVPWM → 驱动逆变器输出PWM

> ⚠️电压模式FOC区别：**去掉电流采样与电流闭环，直接给定Ud、Uq电压指令**，跳过电流PID环节。
> 流程：转子角度获取 → 给定Ud、Uq目标电压 → 逆Park变换 → SVPWM → 逆变器输出。

### 1.2 d/q轴物理意义
- **d轴（直轴）**：转子磁场方向；`Ud`控制磁场，`Ud=0`为最大转矩比控制（Id=0控制）。
- **q轴（交轴）**：垂直转子磁场；`Uq`决定输出转矩大小，Uq越大输出力矩越大。

> 电压模式FOC常用策略：固定`Ud = 0`，调节`Uq`大小控制转矩与转速。

## 二、SVPWM空间矢量PWM实现
SVPWM相比SPWM，直流母线电压利用率提升约15%，是FOC驱动主流方案。
### 算法流程
1. 接收逆Park输出的 `Uα`、`Uβ`；
2. 判断扇区sector；
3. 计算相邻矢量作用时间 `T0,T1,T2`；
4. 计算三相比较值，生成三路互补PWM；
5. 增加过调制保护：当合成电压超过母线电压限制，对幅值做限幅缩放，防止输出饱和。

> 关键注意点
1. 互补PWM必须插入死区时间，防止逆变器上下桥臂直通烧毁功率管；
2. 死区时间不能过大，死区过大会造成低速转矩下降、电流畸变；
3. 电压模式无电流反馈，过调制后无法自动限流，软件必须对Uq最大幅值硬限幅。

伪代码片段
```c
// SVPWM输入 Uα Uβ，输出三相PWM比较值
void svpwm_calc(float u_alpha, float u_beta, uint16_t *cmp_a, uint16_t *cmp_b, uint16_t *cmp_c)
{
    uint8_t sector = calc_sector(u_alpha, u_beta);
    float t1,t2,t0;
    calc_vector_time(u_alpha, u_beta, &t1, &t2, &t0, sector);
    svm_cmp_value(t0,t1,t2,sector,cmp_a,cmp_b,cmp_c);
}
```

## 三、转子角度获取方案

> 
> FOC 的前提：**必须获取实时转子电角度**，角度错误直接导致磁场定向错乱，电机抖动、无法转动。

### 方案 A：霍尔传感器（低成本）

3 路霍尔信号，每 60° 电角度跳变一次。

- 优点：成本低；
- 缺点：角度离散，只有 6 个位置点，需要插值估算中间角度；低速角度分辨率差。

### 方案 B：增量编码器（优先推荐）

正交编码器 AB 相 + Z 零位信号，计数器记录机械角度，乘以极对数换算得到**电角度**。

```
float elec_angle = mechanical_angle * pole_pairs; //电角度 = 机械角度 × 极对数
```

> 
> ⚠️工程坑：编码器相位校准，需要找初始零点，保证电角度和转子磁场对齐；零点错位，电机启动剧烈抖动。

## 四、电压模式 FOC 整体架构（无电流采样）

### 整体执行周期

放在 PWM 更新中断（例如 10kHz）执行：

1. 读取编码器 / 霍尔，计算当前转子电角度 `theta_e`；
2. 设置目标电压：`ud_ref = 0`；根据转速闭环输出`uq_ref`；
3. 逆 Park 变换，输入 ud_ref、uq_ref、theta_e，输出 Uα、Uβ；
4. SVPWM 计算，输出三相 PWM 比较值；
5. 更新定时器 PWM 寄存器。

> 
> 外层主循环：读取转速，执行速度环 PID，输出给到`uq_ref`。

```
【速度环PID】输出 → Uq_ref
Ud_ref = 0
       ↓
逆Park变换(theta_e)
       ↓
Uα Uβ
       ↓
SVPWM
       ↓
三相互补PWM输出（带死区）
```

### 优缺点分析

✅优点

1. 不需要相电流采样电路：省去采样电阻、运放、ADC 通道，硬件 BOM 降低；
2. 代码架构精简，适合低成本 MCU 平台；
3. 可以实现平滑矢量驱动，对比六步方波 BLDC 噪音更小。

❌缺点

1. **没有电流闭环，无法限制绕组电流**；负载堵转时，绕组电流持续上升，有烧毁 MOS 管风险；
2. 动态响应差，负载突变转速跌落明显；
3. 参数敏感，电机 Rs、Ld、Lq 参数不准，会造成转矩下降；
4. 负载过大容易失步。

> 
> 适用场景：风机、小型水泵、轻载持续运行设备；**不适合重载、堵转频发的场景**。

> 
> ⚠️重要安全提示：硬件层面必须增加硬件过流保护，MOS 管侧增加限流，软件增加 Uq 最大限幅，弥补缺少电流闭环的缺陷。

## 五、电机启动、调速与换向逻辑

1. **初始对零（对齐）**
上电先输出固定 d 轴电压，把转子强制拉到已知角度位置，完成初始相位对齐，之后才开启 FOC 运行。如果跳过对齐，电机启动随机抖动，甚至反转。
2. 调速逻辑
外层速度 PID 输出限定到 Uq 允许范围；

- 需要升速 → 增大 Uq；
- 需要减速 → 减小 Uq，可施加负 Uq 实现发电制动。

3. 换向：电角度叠加 180° 实现反转。

## 六、工程实测踩坑记录

1. **电机剧烈抖动，无法正常旋转**
   - 现象：PWM 输出正常，电机高频抖动，原地震荡。
   - 根因 1：转子电角度计算错误，编码器零点错位，磁场定向完全错误。
   - 根因 2：Park / 逆 Park 变换三角函数符号错误，角度单位弧度 / 角度混淆。
   - 解决：重新校准编码器零点；核对坐标变换公式，全部使用弧度。
2. **电机可以转，带一点负载就失步、停转**
   - 现象：空载运行正常，增加负载直接失步。
   - 根因：电压模式没有电流闭环；负载增大，实际需要电流超过电压输出能力；电机参数 Ld Lq 不匹配。
   - 解决：限制最大 Uq 输出；降低目标加速度；优先减轻负载。
3. **低速抖动严重，高速运行尚可**
   - 现象：高速运转顺滑，低速明显脉动。
   - 根因：霍尔角度分辨率不足，角度插值误差大；死区时间过大。
   - 解决：条件允许改用增量编码器；优化霍尔角度插值算法；合理缩减死区时间。
4. **启动瞬间冲击大，直接冲过目标转速**
   - 现象：上电启动猛地窜动。
   - 根因：缺少转子预对齐，直接输出大 Uq 电压；速度环 PID 参数 P 过大。
   - 解决：增加上电角度对齐流程；限制 Uq 上升斜率，做斜坡限制；调低速度环 P 参数。
5. **母线电压下降，电机输出力矩不稳定**
   - 现象：电池供电场景，电池压降，同样 Uq 输出转矩变化。
   - 根因：电压模式直接输出电压指令，没有考虑母线电压波动。
   - 解决：ADC 采集母线电压，根据母线电压动态缩放 SVPWM 输出幅值。
6. **堵转风险，无电流采样无法检测堵转过流**
   - 现象：电机被卡死，MOS 持续输出电压，绕组持续大电流。
   - 根因：电压模式无电流闭环，软件感知不到绕组电流。
   - 解决：硬件增加硬件过流保护；软件检测转速误差，长时间转速达不到目标判定堵转，关闭 PWM 输出。
7. SVPWM 过调制，输出波形畸变
   - 现象：Uq 给大之后电机噪音变大。
   - 根因：合成矢量超过最大母线圆，未做幅值限幅。
   - 解决：增加 SVPWM 幅值饱和缩放，限制输出矢量幅值。

## 七、调参经验总结

1. **先硬件后算法**：先确认三相 PWM、死区、逆变器硬件正常；确认编码器 / 霍尔角度读数正确，再调试 FOC 算法。角度是 FOC 第一优先级。
2. 电压模式 FOC，`Ud`一般固定为 0（Id=0 控制），不要随便修改；依靠 Uq 控制转矩。
3. 速度 PID：P 从很小开始慢慢往上调，P 太大产生震荡；I 消除静差；D 抑制抖动。
4. Uq 必须加斜坡函数，禁止 Uq 瞬间跳变，防止启动、负载突变冲击。
5. 务必设置 Uq 最大输出上限，作为软件层面的限流替代手段。
6. 无电流采样属于硬件妥协方案，产品设计评估风险，必须配套硬件过流保护。
