# HyperDog四足机器狗：整机标定流程与分步调参指南
📄 文档路径：docs/hyperdog-calibration.md
> 标识：🟡
> 配套项目：HyperDog四足机器狗主控+关节伺服固件
> 定位：工程落地标定文档，面向嵌入式调试；包含上电标定、关节零位、IMU校准、逆运动学、步态参数、安全阈值的标定顺序，严格遵循从小到大调参流程，避免全速步态直接炸机。
> 包含：标定顺序、操作步骤、判定标准、参数存储方案、C伪代码、实测踩坑复盘。

## 1. 模块概述
标定核心目标：消除机械装配误差、传感器零偏、结构尺寸偏差，让控制模型匹配真实硬件。
- 标定顺序**严格不可逆**：先静态硬件标定 → 单关节闭环 → 单腿调试 → 整机站立 → Trot小跑；
- 全部标定参数独立存入Flash分区，上电自动加载；
- 单独开启标定模式，正常运行模式禁止写入参数；
- 全流程自带安全保护，参数超限自动锁止电机。

> 核心调试原则：**不调好单关节，绝不调单腿；不调好站立，绝不开启Trot步态**。

## 2. Flash参数分区与结构体
独立Flash分区保存全部标定结果，字段如下：
1. 4路关节零位偏移量
2. IMU陀螺仪、加速度计六轴零偏
3. 连杆几何尺寸（大腿L1、小腿L2、髋部偏置）
4. 步态基础参数：周期、最大步长、抬腿高度、摆动相占比
5. 姿态补偿增益、故障保护阈值

```c
typedef struct
{
    float joint_zero[4];        // 4个关节零位偏移
    float imu_gx_bias;
    float imu_gy_bias;
    float imu_gz_bias;
    float imu_ax_bias;
    float imu_ay_bias;
    float imu_az_bias;
    float link_L1;              // 大腿杆长
    float link_L2;              // 小腿杆长
    float att_comp_gain;        // 姿态补偿增益
    float gait_period_def;      // 默认步态周期
    float step_h_max;           // 最大抬腿高度
    float fault_pitch_thr;      // 倾倒保护倾角阈值
}CalibParam_t;

extern CalibParam_t g_calib_param;
```

## 3. 分步标定流程（严格按顺序执行）
### 步骤1：IMU静态零偏标定
前置条件：整机平放、完全静置，无外力晃动。
1. 进入标定模式；
2. 静置等待3秒，连续采集多组原始IMU数据；
3. 对采样值取平均值，作为六轴零偏补偿值；
4. 校验标准：加速度模值≈9.8m/s²，陀螺仪均值趋近于0；
5. 校验通过才写入Flash；
> 异常拦截：采样期间加速度波动过大，直接拒绝保存，提示重新静置。

### 步骤2：关节编码器零位标定
前置条件：四条腿统一摆到**机械标准零位（垂直站立姿态）**。
1. 下发指令，所有关节进入脱机空载模式；
2. 人工将四条腿固定到统一零位；
3. 主控读取四路编码器原始角度；
4. 偏移计算公式：`joint_zero = -raw_angle`，后续控制指令自动叠加该偏移；
5. 保存零位参数；
> 风险点：零位标反会导致关节反向转动，出现机械干涉。

### 步骤3：单关节FOC闭环调试
仅单关节空载测试，暂不装配腿部结构：
1. 关节使能，开启角度闭环；
2. 给定固定目标角度，观察稳态误差与高频抖动；
3. 分段整定角度环P、I参数；
4. 验收标准：无丢锁、启动无抖动、堵转电流可控；
> 硬性要求：4个关节全部闭环稳定，才可进入下一环节。

### 步骤4：单腿逆运动学IK验证
只装配单条腿，其余三条腿悬空：
1. 输入足端空间坐标，调用逆运动学求解关节目标角度；
2. 对比理论目标位置与实际物理位置；
3. 修正连杆L1、L2长度，补偿加工与装配间隙误差；
4. 测试极限位置，验证机械限位保护逻辑生效。

### 步骤5：整机站立姿态标定
四条腿全部装配完毕，放置在平整地面：
1. 进入`STATE_STAND`待机状态，固定足端支撑点位；
2. 观察机身倾斜情况，微调关节零位或姿态偏置；
3. 由小到大逐步整定姿态补偿增益；
4. 验收标准：轻推机身，机体可以快速回正，无持续震荡；
> 红线：站立自稳不达标，严禁开启小跑步态！

### 步骤6：Trot步态参数标定
整机站立稳定后，再调试小跑动作：
1. 初始保守参数：步态周期拉长至0.8~1.0s、步长极小、低抬腿高度；
2. 缓慢加大步长、缩短步态周期；
3. 重点观察：落地冲击、机身横摆、对角腿相位同步性；
4. 微调摆动相占比、姿态补偿增益；
5. 避开机架共振频率，防止整机剧烈抖动。

### 步骤7：故障安全阈值标定
根据机械硬件设定保护门限：
- 机身倾倒Pitch/Roll保护阈值；
- 关节过流、过热保护阈值；
- 遥控失联超时、CAN总线掉线超时；
> 调试阶段可临时放开阈值；正式运行必须使用保守安全参数。

## 4. 标定模式控制逻辑
```c
// 标定模式入口函数
void Calib_ModeRun(uint8_t calib_step)
{
    switch(calib_step)
    {
        case CALIB_STEP_IMU:
            Calib_IMU_Bias();
            break;
        case CALIB_STEP_JOINT_ZERO:
            Calib_JointZero();
            break;
        case CALIB_STEP_LINK_IK:
            Calib_LinkParam();
            break;
        case CALIB_STEP_SAVE:
            Param_SaveToFlash(&g_calib_param);
            break;
        case CALIB_STEP_LOAD:
            Param_LoadFromFlash(&g_calib_param);
            break;
        default:
            break;
    }
}
```
- 标定模式下直接冻结步态调度器，只执行校准动作；
- 标定过程一旦检测到致命故障，立刻退出标定，执行安全收腿保护。

## 5. 标定完成校验清单（调试必核对）
- [ ] IMU静态标定完成，零偏无异常漂移
- [ ] 4个关节零位方向统一，无反向运动
- [ ] 单关节角度闭环稳定，不存在高频抖动
- [ ] IK正反解自洽，无奇异位置卡死
- [ ] 整机站立具备抗扰动能力，推扰后快速收敛
- [ ] 低速小步Trot无冲击震荡，对角腿相位对齐
- [ ] 所有故障保护触发逻辑正常可靠

## 6. 实测踩坑记录（面试高频考点）
1. IMU标定时机身未放平，零偏参数错误，整机持续单向倾倒；
   解决方案：增加运动检测，机身晃动时直接拒绝采样。
2. 四条腿零位标定姿态不统一，部分腿正向、部分腿反向；
   解决方案：标记机械定位点，四条腿严格保持同一姿态再标定。
3. 连杆尺寸直接照搬CAD图纸，忽略装配间隙，IK解算位置偏差很大；
   解决方案：CAD尺寸仅作为初始值，以实际试凑修正最终杆长。
4. 一上来直接调试高速步态，机械冲击过大损坏减速器；
   解决方案：严格遵守分步调参顺序，始终从低速起步。
5. 姿态补偿增益设置过大，机身轻微倾斜就出现振荡发散；
   解决方案：增益从小到大逐级上调，调到临界稳定后再降低一档。
6. Flash参数写入无CRC校验，掉电后参数损坏；
   解决方案：参数区增加CRC校验，上电校验失败自动加载默认安全参数。
