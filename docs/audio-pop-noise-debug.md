## 概述
POP噪声是音频设备最常见问题，表现为上电、断电瞬间扬声器发出“嘭”的爆破声。本质是运放、DAC输出端电位快速跳变，扬声器振膜受到瞬间冲击。
单纯加大滤波电容只能缓解，无法根除POP声；必须**硬件时序 + 软件控制**配合处理。本文梳理硬件电路、软件策略、完整排查流程，适用于DAC+运放音频输出模块，也可复用电源时序器做多路供电时序管理。

## 一、POP噪声原理
音频DAC、运算放大器需要一个静态偏置电压（单电源供电常用VCC/2）。
- **上电POP**：电源建立过程，输出电位从0V快速拉升至静态偏置，扬声器膜片冲击。
- **掉电POP**：电源快速跌落，输出电位被强制拉向GND，产生反向冲击爆破音。

> 核心思路：**喇叭通路必须在模拟电路稳定之后才打开；断电前先切断喇叭，再关闭模拟电源**。

## 二、硬件抑制方案
### 2.1 MUTE静音电路（首选方案）
使用N-MOS管串联在扬声器回路：
1. 上电时序：数字电源上电 → DAC/运放上电 → 等待偏置稳定 → 解除MUTE，接通喇叭。
2. 下电时序：提前触发MUTE关闭喇叭 → 再切断模拟电源，最后关闭数字电源。

> 工程重点：MUTE控制引脚默认上电为静音状态，避免MCU上电IO浮空瞬间打开喇叭。

### 2.2 RC延时网络（辅助方案）
在运放输出端增加RC滤波，减缓电压上升斜率，降低跳变沿陡度。
缺点：只能减轻噪声，无法完全消除POP；RC电阻过大会衰减音频高频，音质下降。

### 2.3 电源时序控制
数字域、模拟域分开供电：
✅上电顺序：数字电源 → 模拟电源
✅掉电顺序：模拟电源 → 数字电源
模拟基准电压稳定前，禁止打开音频输出通路。电源时序器可统一管理多路电源时序。

## 三、软件抑制方案
### DAC输出斜坡渐变
上电不直接输出目标偏置电压，采用缓慢抬升的方式，避免电位阶跃跳变。
```c
void dac_ramp_up(uint16_t start, uint16_t end, uint16_t step_ms)
{
    uint16_t val;
    for(val = start; val <= end; val++)
    {
        dac_set_output(val);
        HAL_Delay(step_ms);
    }
}
```
- 上电先将DAC输出置0；等待硬件稳定后，缓慢抬升到静态中点电压；之后再送入音频数据流。
- 关闭音频时，缓慢降低输出至0，再触发MUTE静音。

## 四、调试定位方法
1. 示波器探头接音频输出引脚，抓取上电瞬间波形，观察电压跳变沿。
2. 快速定位噪声来源：
    - 上电立刻爆破：DAC/运放偏置电位跳变
    - 断电瞬间爆破：掉电时序问题，没有提前静音
3. 排查顺序：MUTE时序 → 电源上电顺序 → 参考源稳定时间。

## 五、工程实测踩坑记录
1. MUTE时序颠倒，上电直接接通喇叭，POP声无法消除。
> 解决：MCU上电默认MUTE为静音，等待模拟电路稳定再释放静音。
2. 模拟电源与数字电源上电顺序颠倒，产生巨大爆破音。
3. 参考电压上电缓慢，参考源未稳定，DAC已经开始输出。
4. 掉电流程缺失，断电瞬间没有提前关闭MUTE，出现掉电POP。
5. RC滤波电阻取值过大，音频高频衰减，音质变差。
6. IO上电浮空，MUTE控制引脚上电瞬间电平不确定，随机POP。
> 解决：MUTE引脚增加下拉电阻，上电强制保持静音。
