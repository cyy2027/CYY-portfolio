## 概述
PID是工业控制最基础闭环算法，广泛用于电机速度/位置控制、温度、电压电流稳压稳流场景。理论公式简单，但直接套用极易出现超调、震荡、积分饱和、噪声放大等问题。
本文聚焦嵌入式MCU离散PID工程实现，整理抗饱和策略、参数整定流程与现场调试经验，适用于电机、温控、电源闭环项目。

## 一、位置式 vs 增量式PID
### 位置式PID
输出直接对应执行器最终控制量，适合阀门、温控、稳压系统。
$$u(k) = K_p\left[e(k)+\frac{T}{T_i}\sum e(k)+ \frac{T_d}{T}(e(k)-e(k-1))\right]$$
缺点：误差累积，容易出现**积分饱和**；输出依赖全部历史误差。

### 增量式PID
输出为控制量增量，$Δu(k)=u(k)-u(k-1)$
$$\Delta u(k)=K_p\left[\Delta e(k)+\frac{T}{T_i}e(k)+\frac{T_d}{T}(\Delta e(k)-\Delta e(k-1))\right]$$
优点：只计算增量，不会大幅突变；积分饱和风险更低；适合电机PWM增量控制。
> 工程选型：电机FOC速度环优先增量式；温度、电压稳压闭环优先位置式。

## 二、工程改良PID（必须增加，裸公式不能直接上产品）
1. **积分限幅**：对积分项单独限制上下限，防止积分值无限累积。
2. **积分分离**：误差较大时关闭积分，只使用PD控制；误差进入小阈值区间才开启积分，抑制大偏差下超调。
3. **遇限削弱积分Anti-Windup**：输出达到饱和上限时，停止积分累加。
4. **微分先行**：对测量值做微分，不对误差微分，减小设定值阶跃突变带来的冲击。
5. **微分低通滤波**：微分环节对噪声极其敏感，增加一阶RC滤波平滑微分输出。

```c
// 增量式PID简化浮点实现
typedef struct {
    float Kp;
    float Ki;
    float Kd;
    float ek;    // 当前误差
    float ek1;   // 上一次误差
    float ek2;   // 上两次误差
    float out;
    float out_max;
    float out_min;
} pid_inc_t;

float pid_increment_calc(pid_inc_t *pid, float set, float fb)
{
    float delta_u;
    pid->ek = set - fb;
    delta_u = pid->Kp * (pid->ek - pid->ek1)
            + pid->Ki * pid->ek
            + pid->Kd * (pid->ek - 2*pid->ek1 + pid->ek2);
    pid->out += delta_u;
    // 输出限幅
    if(pid->out > pid->out_max) pid->out = pid->out_max;
    if(pid->out < pid->out_min) pid->out = pid->out_min;
    // 更新误差缓存
    pid->ek2 = pid->ek1;
    pid->ek1 = pid->ek;
    return pid->out;
}
```

## 三、工程调参步骤（凑试法，嵌入式现场最实用）
1. **关闭Ki、Kd，只保留Kp**，从小到大增大Kp，系统开始小幅震荡。
2. 降低Kp至震荡刚好消失，记录当前P值。
3. 引入Ki，从小到大缓慢增加积分，消除稳态误差；Ki过大会带来超调与低频震荡。
4. 引入Kd，小幅增加，抑制超调；Kd不能太大，否则放大噪声，系统抖动。
5. 阶跃测试：给设定值阶跃输入，观察波形，反复微调。
> 口诀：**P定响应，I消静差，D抑超调**。

## 四、级联PID（串级闭环）
典型FOC电机：外环位置PID，内环速度PID。
- 内环：响应快，带宽高，抑制扰动。
- 外环：慢响应，负责稳态目标控制。
> 调参顺序：**先内环，后外环；内环调好再调外环**。

## 五、工程踩坑记录
1. 未加积分限幅，目标值突变，积分大量累积，产生巨大超调。
> 解决：开启积分限幅 / 积分分离。
2. 微分项不加滤波，ADC采样噪声被放大，PWM输出剧烈抖动。
> 解决：微分增加一阶低通滤波。
3. PID计算周期不稳定，时快时慢，控制效果变差、震荡。
> 解决：使用固定周期定时器触发PID，用`vTaskDelayUntil`保证周期。
4. 执行器输出饱和后积分继续累加，退出饱和时出现巨大反向超调（积分饱和）。
> 解决：遇限削弱积分Anti-Windup。
5. Kd参数设置过大，系统对噪声敏感，高频抖动。
> 解决：减小Kd，增加滤波。
6. 串级PID直接调外环，内环未稳定，无论怎么调参系统持续震荡。
> 解决：先内环闭环调试稳定，再调试外环。
