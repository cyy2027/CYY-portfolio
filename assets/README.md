# assets/ — 演示媒体目录

各项目页与 showcase 策展页中标注 ⏳ 待补 的证据统一放这里。GitHub 对仓库内媒体有硬约束，先读规则再上传：

| 类型 | 做法 | 限制 |
|---|---|---|
| 视频 | 传 B 站 / YouTube，页面只放**封面 GIF + 外链** | 仓库单文件 <100 MB，>50 MB 会收到仓库体积警告 |
| 封面 GIF | 截 5–10 s 关键片段转 GIF，先压缩 | 目标 <10 MB/个 |
| 音频样本 | mp3 96 kbps、10–20 s/段 | 5 段控制在 2 MB 内 |
| 波形 / 渲染 / 截图 | PNG，宽 ≤1200 px | 不要传原始 4K 截图 |
| 实测数据 | CSV 直接放 `data/`，页面用 Markdown 表展示 | 单文件 <1 MB |

## 子目录

- `video/` — 视频封面 GIF（原视频一律外链）
- `wave/` — 示波器 / 上位机波形截图
- `audio/` — 音频样本（移频前后对比等）
- `board/` — 板卡与整机照片、3D 渲染图
- `data/` — 实测 CSV 数据

> 目前所有目录为空（.gitkeep 占位），对应 showcase 各页中标 ⏳ 的证据项。
